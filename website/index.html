Predictive Architecture

Machine Learning Models

The algorithmic engines translating qualifying delta, historical track form, and racecraft into high-accuracy podium predictions.

PRODUCTION REGRESSION MODEL

Random Forest Regressor (RF-REG-26)

ACTIVE PIPELINE IN PRODUCTION

Random Forest serves as the core regression engine powering Slipstream Oracle. By constructing an ensemble of decorrelated decision trees, the model effectively neutralizes high-variance noise common in Formula 1 weekend sessions while capturing complex nonlinear interactions.

Unlike standard linear models, Random Forest accommodates abrupt disruptions—such as safety car periods, track temperature shifts, and aggressive undercut strategies—without overfitting to individual driver outliers.

Core Feature Importance Weights

  • ▸ Qualifying Sector Delta (34%): Normalized qualifying gap to pole position and teammate delta.
  • ▸ Historical Circuit Form (28%): Multi-year driver pace rating and overtaking success rate at specific circuits.
  • ▸ Constructor Aerodynamic Efficiency (18%): Power-unit output, drag coefficients, and cornering speed index.
  • ▸ Tyre Degradation Modeling (12%): Compound decay profiles and thermal degradation resilience.
  • ▸ Grid Penalty & Position Offsets (8%): Penalties, engine element changes, and pit-lane start offsets.

System Identity & Ethos

About Slipstream Oracle

A Formula 1 prediction laboratory operating from the pit wall.

The Vision

Slipstream Oracle is a personal Formula 1 machine-learning project built around data, experimentation, and the pursuit of better race predictions.

"Where race data meets machine learning. Slipstream Oracle transforms qualifying performance, historical form and race data into data-driven Formula 1 predictions."

The system collects Formula 1 historical data, engineers specialized racing performance features, and applies machine-learning regression models to produce race forecasts. The website transforms those outputs into a visual race-control pit-wall experience.

It is not presented as a replacement for Formula 1 engineering teams or human racing intuition. It is an experimental data-science exploration designed to uncover what empirical racing telemetry can reveal before the five red lights go out.

Pipeline Architecture

STAGE 01
Data Ingestion
Extracting lap times, telemetry sectors, grid penalties, and historical track degradation.
STAGE 02
Feature Synthesis
Computing normalized qualifying deltas, aero efficiency ratings, and tyre compound curves.
STAGE 03
ML Inference
Random Forest regression computes PredictedFinish continuous values and sorts PredictedPositions.
STAGE 04
Pit-Wall UI
Consuming static CSV/JSON files into a cinematic dark glass race-control dashboard.

Technology Stack & Constraints

Built strictly in accordance with modern static-hosting standards:

  • • Frontend: Pure Semantic HTML5, Modular Modern CSS3, and Vanilla ECMAScript 6+ (Zero heavy frameworks, No React, No Next.js).
  • • Data Ingestion: Static CSV and JSON consumption directly from the repository.
  • • Deployment Target: 100% compatible with GitHub Pages static hosting.
  • • Decoupled Core: Slipstream Oracle generates the data; the website presents it.
